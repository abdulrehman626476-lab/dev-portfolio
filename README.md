## 🛠️ Tech Stack & Features

- **Frontend:** HTML5 (Semantic markup), CSS3 (Custom CSS variables, flexbox, responsive grid), Vanilla JavaScript (ES6+).
- **Features:**
  - Dynamic Dark / Light theme switcher with `localStorage` persistence.
  - Fully mobile-responsive navigation menu with accessible ARIA labels.
  - Serverless AJAX contact form integrated with Formspree.
  - Technical SEO configuration (`robots.txt`, `sitemap.xml`, Open Graph meta tags, structured JSON-LD schema).
